# PlaceText v0.3.0

Adobe Illustrator 向けの一括テキスト配置スクリプト（ExtendScript / JSX）。

生のテキストやAI生成原稿、Markdown・テキストファイルを、
ポイント文字（見出し等）と
エリア内文字（本文等）に自動判別して
アートボードにスタック配置します。

## 主な特徴

- **文中記法レスのメタデータ管理UI**:
  - 本文中に専用のタグ記法を書く必要はありません。原稿内の角括弧や記号が構文として誤認されることなく、そのまま安全に配置されます。
  - テキストを貼り付けて「テキストをブロック分割・自動判定」を押すだけで、文字数や空行からポイント文字・エリア内文字を自動判定し、ブロック一覧（ListBox）へ展開します。
  - ブロック一覧でのダブルクリック切替（ポイント ⇔ エリア）や、インスペクタでの個別サイズ・幅・高さ・本文の微調整、ブロック結合・順序移動に対応しています。
- **2タブ構成のすっきりした作業空間**:
  - `'テキスト編集'` タブ: 原稿入力・ブロック一覧・インスペクタを広く使えるように大型化。
  - `'標準設定'` タブ: 分割境界ルール、種別判定、ポイント文字、エリア内文字、配置設定を整理して集約。
- **オブジェクト選択からのテキスト取得**:
  - Illustrator上で選択されている未アウトライン化テキストオブジェクト（TextFrame）から、ワンクリックで文字を抽出して読み込めます。上から下へ配置順に自動ソートされます。
- **Markdown見出し＆明示的種別マーカー対応**:
  - `# ` や `## ` で始まる行を自動的に独立した見出しブロック（ポイント文字）として切り分けます。
  - 先頭に `[P]`, `[A]`, `(P)`, `(A)` を付与することで、文字数閾値に関わらず種別を明示指定できます（マーカーは配置時に自動除去されます）。
- **横書き・縦書き（日本語組版）に対応**:
  - 横書き: 上から下へ重なりなく垂直スタック配置。
  - 縦書き: 右から左へ（日本語の標準組版順序）水平スタック配置。
- **フォント個別指定**:
  - 見出し用・本文用それぞれにフォントを指定可能（小塚ゴシック/明朝、Arial、Helvetica、游ゴシック等のプリセット選択＋PostScript名直接入力）。
- **重なり防止スマートスタック**:
  - 各テキストオブジェクトのバウンディングボックスを自動測定し、指定間隔を空けて自動整列。
- **ファイル読込対応 (TXT / MD / CSV)**:
  - UTF-8（BOM自動除去）およびShift-JIS/CP932に自動対応。読み込みと同時にブロック一覧へ自動展開されます。
- **安心のリアルタイムプレビュー＆コンパクトバー**:
  - プレビュー実行時にウィンドウをミニツールバー（幅640px × 高さ85px）へ自動縮小し、アートボードを広く見渡せます。
- **設定の自動永続化**:
  - 前回設定した数値やフォント、単位（pt/mm/inch）は環境設定ファイルに自動保存され、次回起動時にも引き継がれます。

## インストール・起動方法

### 1. 配布ファイルの取得

リポジトリ内の配布用ファイル `PlaceText.jsx` を使用します。

### 2. スクリプトフォルダへの配置（推奨）

*※ スクリプトフォルダに配置せずエクスプローラ等からスクリプトファイルを開いても利用できます。*

Illustratorのスクリプトフォルダに `PlaceText.jsx` をコピーすると、メニューから直接起動できます。
    ※ スクリプトフォルダに配置後、Illustratorを再起動してください。
- **Windows**:
  `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\<言語>\スクリプト\`
- **macOS**:
  `/Applications/Adobe Illustrator <バージョン>/Presets.localized/<言語>/Scripts/`

### 3. スクリプトの実行

- スクリプトフォルダに配置した場合:
  メニューの `ファイル > スクリプト > PlaceText` を選択。
- 任意の場所に保存した場合:
  メニューの `ファイル > スクリプト > その他のスクリプト...` （Ctrl+F12 / Cmd+F12）から `PlaceText.jsx` を選択。

## クイックスタート（5ステップ）

1. **Illustratorでドキュメントを開く**:
   テキストを配置したいアートボードを表示しておきます。
2. **スクリプトを起動**:
   `PlaceText` を実行するとタブ切り替え式のウィンドウが表示されます。
3. **原稿を用意する**:
   直接テキスト入力欄に文章を貼り付けるか、`'ファイル読込'` ボタンからファイルを選択、またはキャンバス上のテキストを選択して `'選択から取得'` を押します。
4. **「テキストをブロック分割・自動判定」をクリック**:
   設定に基づき各段落が「ポイント文字」または「エリア内文字」として右のブロック一覧に展開されます。一覧のダブルクリックや下の編集欄で個別に調整できます（この手順を省略して直接プレビュー・作成を押しても自動分割されます）。
5. **「プレビュー」で確認し、「テキスト作成」で確定**:
   - `'プレビュー'` を押すとウィンドウがコンパクトに畳まれ、キャンバス上に仮配置されます。
   - `'テキスト作成'` （または畳み状態の `'確定'`）を押すと、テキストオブジェクトが確定配置されてダイアログが閉じます。

## 画面構成・機能詳細ガイド

ウィンドウは「'テキスト編集'」タブと「'標準設定'」タブの2タブ構成です。
各パネルや主要機能にある丸にiのアイコン（ⓘ）をクリックまたはマウスオーバーすると、機能の詳細ヘルプを確認できます。

### タブ1: テキスト編集（原稿入力・ブロック管理）

テキストの入力・読込・分割・メタデータ編集を集約した作業タブです。

- **ソース表示**:
  現在の入力ソース（直接入力 / ファイル名 / 選択オブジェクト件数）を常時表示します。
- **ファイル読込**:
  外部のテキストファイル（`.txt`, `.md`, `.markdown`, `.csv`）を読み込み、自動的にブロック一覧へ展開します。
- **選択から取得**:
  Illustrator上で選択されている未アウトライン化テキストオブジェクト（TextFrame）から本文を一括抽出し、上から下の配置順序で原稿入力欄に展開します。
- **消去**:
  原稿入力欄とブロック一覧をクリアし、初期のモデル文字列表示状態に戻します（`'元に戻す'` で消去前の原稿を復元可能です）。
- **Tab挿入 / 元に戻す / やり直し（編集支援ツールバー＆ショートカット）**:
  原稿入力欄および下部の選択ブロック本文欄の両方で、以下のキーボードショートカットと補助ボタンが利用できます。
  - `Tab` キー / **`'Tab挿入'`**: カーソル位置（または選択範囲）にタブ文字（`\t`）を挿入します。行頭インデントや文中タブも分割時に消去されずそのまま保持されます。
  - `Ctrl+Z` / **`'元に戻す'`**: テキスト入力・貼り付け・ファイル読込・消去などの編集履歴を最大50段階まで遡って元に戻します。
  - `Ctrl+Y`（または `Ctrl+Shift+Z`） / **`'やり直し'`**: 元に戻した編集操作をやり直します。
- **原稿テキスト入力ウィンドウ (420×420px)**:
  - 初回起動時や消去時は、お手本となるモデル文字列が表示されています（文字データとしては未入力扱い）。
  - 入力欄をクリックすると即座に入力可能になります。
- **テキストをブロック分割・自動判定**:
  原稿テキストを解析し、標準設定に従って各ブロックにメタデータ（種別・サイズ・幅・高さ）を付与してブロック一覧へ展開します。
- **ブロック一覧 (ListBox / 430×275px)**:
  分割された各ブロックの `No.`、`種別`（ポイント / エリア）、`サイズ / 幅`、`本文プレビュー` を一覧表示します。
- **ブロック操作ツールバー**:
  `'+ 追加'`, `'- 削除'`, `'上と結合'`, `'上へ'`, `'下へ'` を備えています。
- **選択ブロックのメタデータ編集（インスペクタ）**:
  一覧で選択したブロックの種別、サイズ、エリア幅、エリア高さ、本文を個別に編集できます。

---

### タブ2: 標準設定（分割ルール・種別判定・フォント・配置）

原稿のオブジェクト分割基準とデフォルトの配置スタイルを設定するタブです。

#### 1. ブロック自動分割ルール
原稿をどこで別々のオブジェクトに切り分けるかを設定します。**種別判定とは独立して常に有効に機能します。**
- **特定の境界マーカー**: 指定文字列（例: `---`, `===`, `###`）のある行を境界と認識。
- **検索条件**: `OR検索`（空行またはマーカー） / `AND検索`（空行かつマーカー）。
- **空行の数**: 指定行数の連続空行で分割（初期値: 1行）。
- **Markdown見出し (#)**: `# ` や `## ` で始まる行を自動的に独立した見出しブロックとして切り分けます。

#### 2. オブジェクト種別判定ルール
各ブロックをポイント文字にするかエリア内文字にするかの基準を設定します。
- **判定モード**: `自動判定（文字数閾値・マーカー準拠）` / `すべてポイント文字` / `すべてエリア内文字`。
- **インライン種別マーカー**: `[P]`, `[A]`, `(P)`, `(A)` を認識して種別を決定し、本文から除去します。
- **文字数閾値**: 1ブロックの文字数がこの閾値以上の場合に「エリア内文字」、未満を「ポイント文字」と自動判定します（初期値: 30文字）。

#### 3. ポイント文字
- **文字サイズ**: 標準文字サイズと単位（pt / mm / inch）。
- **フォント**: ポイント文字用フォント。プリセット選択のほか、「直接入力 (自由入力)」で任意のフォントを指定可能。横の **`[検索...]`** ボタンをクリックすると、Illustrator内の全フォントからリアルタイムに絞り込み検索・サジェスト選択できる専用ダイアログが開きます。PostScript名（例: `ArialMT`, `FOT-BokutoReraStd-DB`）だけでなく日本語フォント名（例: `墨東レラ`, `ヒラギノ角ゴ`）でも検索・自動解決されます。

#### 4. エリア内文字
- **文字サイズ**: 標準文字サイズと単位。
- **エリア幅**: テキストフレームの横幅。
- **エリア高さ (0=自動)**: テキストフレームの高さ。`0` で文字量から自動計算。
- **フォント**: エリア内文字用フォント（ポイント文字と同様にプリセット・直接入力・`[検索...]` サジェストに対応）。

#### 5. 配置設定
- **書字方向**: `横書き (水平)` / `縦書き (垂直)`。
- **オブジェクト間隔**: オブジェクト同士の余白（マージン）。
- **配置基準**: `選択直下` / `アートボード基準`。

### 最下部: ステータス＆アクション

- **通常時（展開時）のアクションバー**:
  - **ステータス表示**: 現在の文字数カウントやブロック数、ファイル読込完了状況をリアルタイムに表示。
  - **'プレビュー'**: キャンバス上に仮配置し、アートボードを広く見渡せるように**ウィンドウをコンパクトなミニツールバー（幅640px × 高さ85px）へ自動縮小**します。
  - **'テキスト作成'**: オブジェクトを確定配置し、ダイアログを閉じます。
  - **'キャンセル'**: 処理を実行せずにダイアログを閉じます。
- **プレビュー時（畳み時・コンパクトバー）の3ボタン**:
  - **`'編集に戻る'`**: ウィンドウを元の画面へ再展開し、設定の調整やテキスト編集を再開します（生成されたプレビューはキャンバス上に保持されます）。
  - **`'確定'`**: プレビューオブジェクトを破棄し、正式なテキストオブジェクトとして確定配置してダイアログを閉じます。
  - **`'キャンセル'`**: プレビューオブジェクトを全削除し、ダイアログを閉じます。

## ブロック一覧・メタデータ編集リファレンス

ブロック一覧と下部インスペクタを使うことで、本文中に記号やタグを一切記述することなく、ブロック単位で細かな制御が可能です。

### 1. ワンタッチ種別切替（ダブルクリック）

- ブロック一覧の行を**ダブルクリック**すると、そのブロックの種別が `ポイント` ⇔ `エリア` の間で即座に切り替わります。
- 切り替え時には、設定されているポイント文字またはエリア内文字の標準サイズ・幅が自動適用されます。

### 2. ブロックの追加・削除・結合・順序変更

- **`'+ 追加'`**: 選択中のブロックの直後（未選択時は末尾）に新しいブロックを追加します。
- **`'- 削除'`**: 選択中のブロックを一覧から削除します。
- **`'上と結合'`**: 選択中のブロックを1つ上のブロックに空行付きで結合します。空行で分割された複数の段落を、1つのエリア内文字オブジェクトにまとめたい場合に便利です。
- **`'上へ'` / `'下へ'`**: 選択中のブロックの配置順序を前後に移動します。

### 3. 個別メタデータの編集（インスペクタ）

- **種別**: ラジオボタンで `ポイント` または `エリア` を選択できます。
- **サイズ**: そのブロックだけの文字サイズを個別に変更できます。
- **エリア幅 / 高さ(0=自動)**: エリア内文字の場合に、そのブロックだけのフレーム幅・高さを個別に指定できます。
- **本文**: そのブロックのテキスト内容を直接修正できます。

## エラーコード一覧

エラー発生時はダイアログにエラーコードが表示されます。原因特定にご活用ください。

| コード       | 名称                   | 原因と対処法                                                |
| :-------- | :------------------- | :---------------------------------------------------- |
| `ERR_001` | NO_DOCUMENT          | ドキュメントが開かれていません。アートボードを作成・オープンしてから実行してください。           |
| `ERR_002` | TARGET_LAYER_INVALID | 編集可能なレイヤーが見つかりません。レイヤーのロックや非表示を解除してください（自動生成に失敗した場合）。 |
| `ERR_003` | EMPTY_TEXT           | 配置するテキストが入力されていません。文字を入力するかファイルを読み込んでください。            |
| `ERR_004` | PARSE_FAILED         | テキストのブロック分割・解析処理に失敗しました。                          |
| `ERR_005` | LAYOUT_FAILED        | テキストオブジェクトの生成・座標計算に失敗しました。                            |
| `ERR_006` | FILE_IO_FAILED       | 外部ファイルの読み込みに失敗しました。ファイルの文字コードやアクセス権限を確認してください。        |
| `ERR_007` | PREVIEW_FAILED       | プレビューオブジェクトの生成・再描画に失敗しました。                            |
| `ERR_008` | CONFIG_FAILED        | 設定ファイル（`settings.json`）の読み書きに失敗しました。                  |
