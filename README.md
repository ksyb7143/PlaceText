# PlaceText v1.0.0

Adobe Illustrator 向けの一括テキスト流し込み・自動レイアウト配置スクリプト（ExtendScript / JSX）。

外部原稿ファイル（`.txt`, `.md`, `.csv`, `.tsv`）、直接入力、またはキャンバス上の選択テキストオブジェクトから文章を取得し、見出し（ポイント文字）と本文段落（エリア内文字）を自動判別・分割して、アートボード上に縦1列・横1列・2Dグリッドで美しく整列配置します。

## 主な特徴

- **文中記法不要のスマートメタデータ管理**:
  - 原稿内に専用タグを埋め込む必要はありません。文章内の角括弧（`[...]`）や記号が誤認されることなく安全に保持されます。
  - テキストを貼り付けて「自動テキスト分割・属性判定」を押すだけで、文字数や空行・見出し記号からポイント文字／エリア内文字を自動判定し、5列のユニット一覧（ListBox）へ展開します。
- **チェックボックス選択と4行インスペクタ**:
  - ユニット一覧の `[ ]` / `[ ✓ ]` チェックボックスにより、単一ユニットの編集はもちろん、複数ユニットの一括属性変更（フォントサイズ、文字揃え、行長・行数・行配置など）が直感的に行えます。
  - 選択中の組み方向（横書き／縦書き／混在）に連動して、文字揃え（`左揃え` $\leftrightarrow$ `上揃え`）や行配置（`上揃え` $\leftrightarrow$ `右揃え`）のラベルが動的に切り替わります。
- **Illustrator選択オブジェクトの読み込み・一括更新**:
  - キャンバス上の未アウトライン化テキストオブジェクト（TextFrame）を選択して「選択オブジェクト」を押すだけで、配置順（Y座標降順）に文字を抽出し、文面・文字サイズ・文字揃えの更新やオブジェクト削除を一括処理できます。
- **Markdown / CSV / TSV に完全対応**:
  - **Markdown**: 見出し（H1〜H6）の独立ブロック化・文字サイズ個別反映、箇条書きの自動分割、および箇条書き記号（`-`, `*`）から Illustrator の `・` リスト形式への変換（ぶら下げインデント自動設定）に対応。
  - **CSV / TSV**: RFC 4180準拠パーサー（クォート内改行・カンマ・エスケープ対応）。「セルごとに分割」「行ごとに分割」「列ごとに分割」「表全体」の4つの分割単位と配置レイアウトが完全連動し、空セルや削除セルのグリッド座標ズレを防止します。
- **2Dグリッド配置（縦1列・横1列・N行M列）**:
  - オブジェクトの実測バウンディングボックスに基づき、指定間隔を空けて重なりなく整列配置します。
- **フォント検索・サジェスト機能**:
  - Illustratorにインストールされている全フォントをリアルタイムに絞り込み検索できる専用モーダルを搭載。日本語フォント名やPostScript名での検索に対応しています。
- **プレビュー自動縮小モード（コンパクトバー）**:
  - プレビュー実行時にウィンドウが幅360px × 高さ90pxのミニツールバーへと自動的に折りたたまれるため、アートボード上の配置結果を遮ることなく確認できます。
- **安心のテキスト編集支援**:
  - 原稿入力欄およびインスペクタ本文欄の双方で、`Tab` キー挿入、最大50段階の Undo（`Ctrl+Z`）/ Redo（`Ctrl+Y`）、および制御文字（タブ・改行・ノーブレークスペース等）の可視化エスケープ表示（`制御文字を表示/非表示`）に対応しています。
- **設定のJSON書き出し・読み込み・自動永続化**:
  - 作業環境の設定は自動保存されるほか、外部JSONファイルへの書き出し・読み込みおよび初期値へのリセットに対応しています。

## インストール・起動方法

### 1. スクリプトファイルの配置（推奨）

_※ スクリプトフォルダに配置せずエクスプローラ等からスクリプトファイルを開いても利用できます。_

リポジトリ内の `PlaceText.jsx` を、Illustratorのスクリプトフォルダにコピーします。

- **Windows**:
  `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\<言語>\スクリプト\`
- **macOS**:
  `/Applications/Adobe Illustrator <バージョン>/Presets.localized/<言語>/Scripts/`

※ 配置後、Illustratorを再起動してください。

### 2. スクリプトの実行

- スクリプトフォルダに配置した場合:
  Illustratorメニューの `ファイル > スクリプト > PlaceText` を選択。
- 任意のフォルダから直接実行する場合:
  Illustratorメニューの `ファイル > スクリプト > その他のスクリプト...` （ショートカット: `Ctrl+F12` / `Cmd+F12`）から `PlaceText.jsx` を選択。

## クイックスタート（5ステップ）

1. **アートボードを用意**:
   テキストを配置したいIllustratorドキュメントを開きます。
2. **PlaceTextを起動**:
   メニューから実行すると2タブ構成のダイアログが表示されます。
3. **テキストを用意**:
   - 直接テキストボックスに文章を貼り付ける
   - `'ファイル読込'` ボタンから `.txt`, `.md`, `.csv`, `.tsv` を開く
   - キャンバス上でテキストオブジェクトを選択して `'選択オブジェクト'` を押す
4. **「自動テキスト分割・属性判定」をクリック**:
   原稿が段落ごとに自動分割され、右ペインの一覧に展開されます。一覧のチェックボックス（`[ ✓ ]`）で選択し、下のインスペクタでサイズや行長などを自由に調整できます。
5. **「プレビュー」で確認し、「作成」で確定**:
   - `'プレビュー'` を押すとウィンドウが小さく折りたたまれ、キャンバス上に仮配置されます。
   - 配置を確認したら `'作成'` を押すことで正式なオブジェクトとして確定配置されます。

## 画面構成・機能詳細ガイド

メインウィンドウは **「編集タブ」** と **「標準設定タブ」** の2タブ構成です。

### 編集タブ（原稿入力・ユニット一覧・個別インスペクタ）

日常的なテキストの入力・分割・属性調整を集約したメイン作業画面です。

#### 左ペイン（幅440px）
1. **フレーム「ソース選択」**:
   - **`ファイル読込`**: `.txt`, `.md`, `.csv`, `.tsv` ファイルを選択して読み込み、形式を自動判定してユニット一覧へ即座に展開します。
   - **`直接入力`**: テキスト入力欄にフォーカスを戻し、手動入力モードにします。
   - **`選択オブジェクト`**: 選択されている既存TextFrameを取得します（取得時は赤字で警告が表示され、オブジェクト削除・文面・サイズ・文字揃えの変更が可能になります）。
   - **ソース表示**: 現在の入力ソース状態（ファイル名、直接入力、選択オブジェクト件数）を常時表示します。
2. **フレーム「テキスト編集」**:
   - **`元に戻す` / `やり直す`**: 最大50段階のテキスト編集履歴を操作します（`Ctrl+Z` / `Ctrl+Y` 対応）。
   - **`Tab挿入`**: カーソル位置にタブ文字（`\t`）を挿入します。
   - **`制御文字を表示/非表示`**: 原稿内のタブ（`\t`）や改行（`\n`）、ノーブレークスペース（`\u00A0`）などの制御文字をエスケープ文字列として可視化／通常表示をトグルします。
   - **テキスト入力ボックス**: 原稿テキストを入力・編集します（未入力時はお手本となるモデル文字列を淡い色で表示）。
   - **`形式 :` プルダウン**: 現在のテキストを `TXT(プレーンテキスト)` / `Markdown` / `CSV・TSV` のいずれとして解釈するかを指定します。
   - **`自動テキスト分割・属性判定` ボタン**: 原稿を解析してユニット一覧へ展開します（テキストや設定変更時は `分割・属性を再定義` に変化しオレンジ警告色で再分割を促します）。

#### 右ペイン（幅450px）
1. **フレーム「ユニット属性の編集」**:
   - **一括変更ボタン群**:
     - `すべて選択/すべて解除`: 全ユニットのチェックボックス（`[ ✓ ]` / `[ ]`）を一括トグルします。
     - `すべてポイント文字`: チェック中のユニット（未選択時は全ユニット）をポイント文字に変更します。
     - `すべてエリア内文字`: チェック中のユニット（未選択時は全ユニット）をエリア内文字に変更します。
   - **ユニット一覧（5列 ListBox）**:
     - 第1列 `select`: `[ ]` / `[ ✓ ]`（行クリックやSpaceキーで選択切り替え）。
     - 第2列 `No.`: ユニット番号。
     - 第3列 `タイプ`: `ポイント` / `エリア` / `ポイント(縦)` / `エリア(縦)` / `削除`。
     - 第4列 `文字サイズ/エリア幅/高さ`: 例 `14pt`、`10pt / 幅300pt` 等。
     - 第5列 `プレビュー`: 先頭本文の要約表示（空セルは `[空セル]`、削除マーク時は `[削除済み]`）。
   - **ユニット操作ツールバー**:
     - `選択したユニットを削除`: チェックの入ったユニットを削除します（未チェック時は安全のため動作せずグレーアウトします。選択オブジェクト時およびCSVセル分割時は削除マークトグルとして動作）。
     - `上に結合`: チェック中のユニットを直前のユニットと結合します。
     - `上へ移動` / `下へ移動`: チェック中のユニットの配置順序を前後に入れ替えます。
2. **フレーム「選択ユニットの編集」（4行インスペクタ）**:
   - 一覧でチェックされているユニットの属性を表示・編集します（複数選択時は一括変更、未チェック時は誤操作防止のためグレーアウト）。
   - **Row 1（種類と組み方向）**: `ポイント文字` / `エリア内文字`、`横書き` / `縦書き`。
   - **Row 2（文字サイズと文字揃え）**: `文字サイズ`（数値＋`pt`/`mm`/`px`）、`文字揃え`（組み方向に連動して `左揃え` $\leftrightarrow$ `上揃え` 等に動的変化）。
   - **Row 3（エリア組版設定）**: エリア内文字選択時のみ有効。`行長`（数値＋`pt`/`mm`/`px`）、`行数`（`0`=自動計算、数値＋`行`/`pt`/`mm`/`px`）、`行配置`（組み方向に連動して `上揃え` $\leftrightarrow$ `右揃え` 等に動的変化）。
   - **Row 4（本文編集）**: 選択ユニットの文章を直接修正します（複数選択時は `"複数選択中"` となり編集ロック）。

### 標準設定タブ（分割基準・属性判定・書式・形式別詳細設定）

分割のルールや初期値のフォーマットを設定するタブです。左右2列構成で整理されています。

#### 左列（幅445px）
1. **フレーム「自動分割の基準」**:
   - **検索方法**: `OR検索`（マーカーまたは空行を満たせば分割） / `AND検索`（マーカーかつ空行の双方を満たす場合のみ分割）。
   - **特定のマーカー**: `---` / `===` / `***` / `入力したマーカー`（最大5文字、リアルタイム文字種バリデーション付き）。
   - **空行の数**: 指定行数以上の連続空行を境界として認識（初期値: 1行）。
   - **テキストの形式に基づく分割**: MarkdownやCSVの構文に基づく自動切り分けを有効にするチェックボックス。
2. **フレーム「属性判定」**:
   - **判定モード**: `自動判定` / `すべてポイント文字` / `すべてエリア内文字`。
   - **文字数**: 指定文字数以上で自動的にエリア内文字と判定する閾値（初期値: 30文字）。
   - **マーカー判定**: 原稿先頭の `[P]`, `[A]`, `(P)`, `(A)` を認識して種別を決定し、本文配置時にマーカーを自動除去します。
3. **フレーム「ユニット属性ごとの設定」**:
   - **【ポイント文字】**: `文字サイズ`、`組み方向`、`文字揃え`、`フォント`（プリセット＋直接入力＋`検索` ボタン）。
   - **【エリア内文字】**: `文字サイズ`、`組み方向`、`文字揃え`、`フォント`、標準 `行長`、標準 `行数`、標準 `行配置`。

#### 右列（幅445px）
1. **フレーム「解釈形式ごとの設定」**:
   - プルダウンで `Markdown` または `CSV/TSV` を選択し、詳細設定パネルを切り替えます。
   - **Markdown設定**:
     - `見出しの分割設定`: 独立ユニット（ポイント文字/エリア内文字）、直前・大見出しごと結合。
     - `見出しごとのサイズ設定`: H1〜H6の文字サイズを個別指定。
     - `見出しの#の処理`: 隠す / ソースモードのまま。
     - `箇条書きの分割`: 項目ごと / ネスト親ごと / ブロック全体。
     - `箇条書きの記号の処理`: 隠す / ソースのまま / `Illustratorの箇条書きリスト形式に変換`（`・` 記号化＋ぶら下げインデント適用）。
     - `コメントアウトの処理`: `<!-- ... -->` を無視する / ソースのまま。
   - **CSV/TSV設定**:
     - `分割単位`: `セルごとに分割` / `行ごとに分割` / `列ごとに分割` / `表全体を1つのユニットとする`。
     - `列の連結文字`: タブ `\t` / 半角スペース / 全角スペース / カンマ `,` / スラッシュ ` / `。
     - `1行目の扱い`: 通常データとして含める / 1行目を除外する (見出し行スキップ)。
     - `区切り文字`: 自動判定 (カンマ/タブ) / カンマ固定 (CSV) / タブ固定 (TSV)。
2. **フレーム「設定の書き出し・読み込み」**:
   - `設定の書き出し`: 現在の設定を外部 `.json` ファイルへ保存。
   - `設定の読み込み`: 外部 `.json` ファイルから設定を復元。
   - `初期値にリセット`: 全標準設定を初期値へ戻します。

### 最下部バー（ステータス・配置設定・プレビュー・作成）

- **ステータス表示**: 文字数やユニット数、操作ガイドを常時表示します。
- **`配置設定` ボタン**: 「配置・レイアウト設定」モーダルダイアログを起動します。
- **`プレビュー` ボタン**: キャンバス上に仮テキストフレームを生成し、ウィンドウをコンパクトバー（360×90px）へ縮小します。
  - コンパクトバー表示中は `編集に戻る`（プレビューを保持したまま編集画面へ復帰）、`作成`（確定配置して閉じる）、`キャンセル`（破棄して閉じる）が利用できます。
- **`作成` ボタン**: 設定内容でアートボード上へテキストオブジェクトを本配置（または選択オブジェクトを更新）してダイアログを閉じます。
- **`キャンセル` ボタン**: 変更を行わずにダイアログを閉じます。

## モーダルダイアログ機能

### 配置・レイアウト設定

メイン画面最下部の `'配置設定'` ボタンから呼び出します。

1. **並び順・レイアウト**:
   - `縦1列`: 上から下へスタック配置。
   - `横1列`: 左から右へスタック配置（縦書き時は右から左へ配置）。
   - `グリッド (列数指定)`: 指定した列数 $M$ で折り返して2Dマトリクス配置。
   - `グリッド (行数指定)`: 指定した行数 $N$ で折り返して配置。
   - ※ CSV形式分割が有効な場合は、分割単位（セル＝列数指定グリッド、行＝縦1列、列＝横1列）に応じて自動設定され、安全のためパネルが自動ロックされます。
2. **オブジェクト間隔**:
   - `行間隔` および `列間隔`（数値＋`pt`/`mm`/`px`）。
   - `行・列の間隔を同一にする` チェックボックス。
3. **配置基準位置**:
   - `選択直下`: キャンバス上の選択オブジェクトの直下（または左隣）を開始位置とする。
   - `アートボード基準`: 現在のアートボードの左上（縦書き時は右上）を開始位置とする。

### フォント検索・サジェスト

標準設定タブの各フォント行にある `'検索'` ボタンから呼び出します。

- 検索窓にフォント名（例: `ゴシック`, `Arial`, `小塚`, `Mincho` 等）を入力すると、部分一致でリアルタイムに候補を絞り込みます（最大80件表示）。
- リストボックスには「フォント表示名（Family + Style）」と「PostScript名」が2列で表示され、ダブルクリックまたは `'このフォントを適用'` ボタンで即座に設定へ反映されます。

## 形式別解釈仕様（TXT / Markdown / CSV・TSV）

| 形式 | 主な仕様・動作 |
| :--- | :--- |
| **TXT (プレーンテキスト)** | 空行数および境界マーカー（`---` 等）に基づく分割、文字数閾値判定、`[P]`/`[A]` マーカー認識 |
| **Markdown** | 見出し記号（`# `〜`###### `）による自動分割、見出し別文字サイズ自動適用、箇条書きリスト変換（`・`＋インデント）、HTMLコメント（`<!-- -->`）除去 |
| **CSV / TSV** | RFC 4180準拠パーサー（クォート内改行・カンマ保持、不足列パディング）、4分割単位連動、空セル座標維持（列ズレ防止）、ヘッダー行スキップ |

## エラーコード一覧

エラー発生時はダイアログにエラーコードが表示されます。

| コード       | 名称                     | 内容と対処方法                                    |
| :-------- | :--------------------- | :----------------------------------------- |
| `ERR_001` | `NO_DOCUMENT`          | ドキュメントが開かれていません。アートボードを作成または開いてから実行してください。 |
| `ERR_002` | `TARGET_LAYER_INVALID` | 編集可能なレイヤーが見つかりません。レイヤーのロックや非表示を解除してください。   |
