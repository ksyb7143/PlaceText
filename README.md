# PlaceText v0.2.0

Adobe Illustrator 向けの一括テキスト配置スクリプト（ExtendScript / JSX）。

生のテキストやAI生成原稿、Markdown・テキストファイルを、
ポイント文字（見出し等）と
エリア内文字（本文等）に自動判別して
アートボードにスタック配置します。

## 主な特徴

- **2段階ハイブリッドUI**:
  - テキストを貼り付けて「自動タグ付け」を押すだけで、文字数や空行からポイント文字・エリア内文字を自動判定して識別タグをつける。
  - テキスト入力欄でインラインタグ（`[P: 14pt]`, `[A: 10pt, 300x400pt]`）を直接自由に編集・微調整可能。
- **横書き・縦書き（日本語組版）に対応**:
  - 横書き: 上から下へ重なりなく垂直スタック配置。
  - 縦書き: 右から左へ（日本語の標準組版順序）水平スタック配置。
- **フォント個別指定**:
  - 見出し用・本文用それぞれにフォントを指定可能（小塚ゴシック/明朝、Arial、Helvetica、游ゴシック等のプリセット選択＋PostScript名直接入力）。
- **重なり防止スマートスタック**:
  - 各テキストオブジェクトのバウンディングボックスを自動測定し、指定間隔を空けて自動整列。
- **ファイル読込対応 (TXT / MD / CSV)**:
  - UTF-8（BOM自動除去）およびShift-JIS/CP932に自動対応。
- **安心のリアルタイムプレビュー**:
  - キャンバス上に仮配置して配置バランスを確認可能。ダイアログ終了時に自動消去されます。
- **設定の自動永続化**:
  - 前回設定した数値やフォント、単位（pt/mm/inch）は環境設定ファイルに自動保存され、次回起動時にも引き継がれます。

## インストール・起動方法

### 1. 配布ファイルの取得

リポジトリ内の配布用ファイル `PlaceText.jsx`を使用します。

### 2. スクリプトフォルダへの配置（推奨）

*※ スクリプトフォルダに配置せずエクスプローラ等からスクリプトファイルを開いても利用できます。*

Illustratorのスクリプトフォルダに `PlaceText.jsx` をコピーすると、メニューから直接起動できます。
    ※ スクリプトフォルダに配置後、Illustratorを再起動してください。
- **Windows**:
  `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\<言語>\スクリプト\`
- **macOS**:
  `/Applications/Adobe Illustrator <バージョン>/Presets.localized/<言語>/Scripts/`



### 3. スクリプトの実行

- スクリプトフォルダに配置した場合:
  メニューの `ファイル > スクリプト > PlaceText` を選択。
- 任意の場所に保存した場合:
  メニューの `ファイル > スクリプト > その他のスクリプト...` （Ctrl+F12 / Cmd+F12）から `PlaceText.jsx` を選択。

*※ スクリプトフォルダに配置せずエクスプローラ等からスクリプトファイルを開いても利用できます。*

## クイックスタート（5ステップ）

1. **Illustratorでドキュメントを開く**:
   テキストを配置したいアートボードを表示しておきます。
2. **スクリプトを起動**:
   `PlaceText` を実行すると2ペインのウィンドウが表示されます。
3. **原稿を用意する**:
   直接テキスト入力欄に文章を貼り付けるか、
   `[ファイル読込 (TXT/MD)]` ボタンからファイルを選択します。
4. **「自動タグ付け」をクリック**:
   右ペインの設定（文字数閾値など）に基づき、各段落の先頭に `[P: ...]` や `[A: ...]` のタグが自動挿入されます。必要に応じて手動で数値を修正できます。
5. **「プレビュー」で確認し、「テキスト作成」で確定**:
   - `[プレビュー]` を押すとキャンバス上に仮配置されます。
   - `[テキスト作成]` を押すと、テキストオブジェクトが確定配置されてダイアログが閉じます。

## 画面構成・機能詳細ガイド

ウィンドウは「左ペイン（テキスト入力）」と「右ペイン（標準設定）」の2ペイン構成です。
各項目にある丸にiのアイコン（ⓘ）をクリックまたはマウスオーバーすると、機能の詳細ヘルプを確認できます。

### 左ペイン: テキスト入力・タグ管理

- **使い方・記法説明**:
  インラインタグ記法の簡単な書式が表示されます。
- **ファイル読込 (TXT/MD)**:
  外部のテキストファイル（`.txt`, `.md`, `.markdown`, `.csv`）を読み込みます。改行コードは自動正規化され、Windows環境でも安全に表示されます。
- **テキスト消去**:
  入力欄をクリアし、初期のモデル文字列表示状態に戻します。
- **テキスト入力ウィンドウ**:
  - 初回起動時や消去時は、お手本となる**モデル文字列**が表示されています（文字データとしては未入力扱い）。
  - 入力欄をクリックすると即座に入力可能になります。
  - ここでタグや本文を直接タイピング・編集できます。
- **自動タグ付け**:
  入力テキストを解析し、右ペインの設定に従って各ブロック先頭に `[P: ...]`（ポイント文字）や `[A: ...]`（エリア内文字）のタグを自動挿入します。

---

### 右ペイン: 標準設定

#### 1. 自動判定の閾値設定

- **すべてポイント文字 / すべてエリア内文字**:
  文字数にかかわらず、すべての段落を強制的にポイント文字（またはエリア内文字）としてタグ付けする一括モードです。
- **特定の境界マーカー**:
  空行だけでなく、指定した目印（例: `---`, `===`, `###`）のある行をオブジェクトの境界として認識します。
  - 定番プリセット（`---`, `===`, `###`, `***`, `///`）または「自由入力」（半角英数記号5文字以内）が選べます。
  - ※注意: 本文中にマーカーと同じ文字列があると意図しない分割の原因となるため、固有記号か「AND検索」を使用してください。
- **条件の検索方法**:
  - `OR検索`: 指定空行または境界マーカーのいずれかが出現した位置で分割。
  - `AND検索`: 境界マーカーの前後に指定空行がある場合のみ分割。
- **文字数**:
  1ブロックの文字数がこの閾値以上の場合に「エリア内文字 `[A]`」、未満を「ポイント文字 `[P]`」と自動判定します（初期値: 30文字）。
- **空行の数**:
  オブジェクトの区切りとみなす連続した空行の数です（初期値: 1行）。

#### 2. ポイント文字

- **文字サイズ**:
  ポイント文字（見出し等）の文字サイズと単位（pt / mm / inch）を指定します。
- **フォント**:
  ポイント文字に適用するフォントを指定します。
  - プリセット（小塚ゴシック、小塚明朝、Arial、Helvetica、游ゴシック等）
  - 「直接入力」を選択すると、任意のPostScriptフォント名を直接入力できます。未指定の場合はIllustratorの既定フォントが適用されます。

#### 3. エリア内文字

- **文字サイズ**:
  エリア内文字（本文・段落等）の文字サイズと単位を指定します。
- **エリア幅**:
  テキストフレームの横幅を指定します。本文はこの幅で自動折り返しされます。
- **エリア高さ (0=自動)**:
  テキストフレームの高さを指定します。`0` を指定すると、文字量とフォントサイズから高さを自動計算してあふれ（オーバーフロー）を防ぎます。
- **フォント**:
  エリア内文字に適用するフォントを指定します。

#### 4. 配置設定

- **書字方向**:
  - `横書き (水平)`: 水平方向に文字が並び、上から下へ垂直にスタック配置されます。
  - `縦書き (垂直)`: 垂直方向に文字が並び、右から左（日本語組版標準）へ水平にスタック配置されます。
- **オブジェクト間隔**:
  オブジェクト同士の余白（マージン）を指定します。
- **配置基準**:
  - `選択直下`: キャンバス上で現在選択されているオブジェクトの直下（縦書き時は左隣）から配置を開始します。
  - `アートボード基準`: アクティブなアートボードの余白（横書き時は左上、縦書き時は右上）から配置を開始します。

---

### 最下部: ステータス＆アクション

- **ステータス表示**:
  現在の文字数カウントやファイルの読込完了状況などをリアルタイムに表示します。
- **プレビュー**:
  キャンバス上に一時的なテキストオブジェクトを生成して仕上がりを確認できます。ダイアログを閉じると自動的に破棄されます。
- **テキスト作成**:
  現在の設定とテキストでオブジェクトを確定配置し、ダイアログを閉じます。
- **キャンセル**:
  処理を実行せずにダイアログを閉じます。

## インラインタグ記法リファレンス

入力欄では、各段落の先頭にタグを記述することで、個別にサイズや幅をコントロールできます。

### ポイント文字（Point Text）

1行の見出し、キャッチコピー、ラベル向け。

- 書式: `[P: <文字サイズ>]`
- 例: `[P: 24pt]`, `[P: 10mm]`

### エリア内文字（Area Text）

複数行の本文、段落、説明文向け。

- 書式: `[A: <文字サイズ>, <フレーム幅>]`
- 例: `[A: 10.5pt, 300pt]`, `[A: 12pt, 80mm]`
- 高さを明示する場合: `[A: <文字サイズ>, <幅>x<高さ>]` （例: `[A: 10pt, 300ptx150pt]`）

### タグなしブロックの挙動

タグが書かれていないブロックには、直前のブロックの設定、または右ペインで指定された標準設定値が自動適用されます。

## エラーコード一覧

エラー発生時はダイアログにエラーコードが表示されます。原因特定にご活用ください。

| コード       | 名称                   | 原因と対処法                                                |
| :-------- | :------------------- | :---------------------------------------------------- |
| `ERR_001` | NO_DOCUMENT          | ドキュメントが開かれていません。アートボードを作成・オープンしてから実行してください。           |
| `ERR_002` | TARGET_LAYER_INVALID | 編集可能なレイヤーが見つかりません。レイヤーのロックや非表示を解除してください（自動生成に失敗した場合）。 |
| `ERR_003` | EMPTY_TEXT           | 配置するテキストが入力されていません。文字を入力するかファイルを読み込んでください。            |
| `ERR_004` | PARSE_FAILED         | テキストの構文解析に失敗しました。タグの閉じ括弧 `]` 等の不整合を確認してください。          |
| `ERR_005` | LAYOUT_FAILED        | テキストオブジェクトの生成・座標計算に失敗しました。                            |
| `ERR_006` | FILE_IO_FAILED       | 外部ファイルの読み込みに失敗しました。ファイルの文字コードやアクセス権限を確認してください。        |
| `ERR_007` | PREVIEW_FAILED       | プレビューオブジェクトの生成・再描画に失敗しました。                            |
| `ERR_008` | CONFIG_FAILED        | 設定ファイル（`settings.json`）の読み書きに失敗しました。                  |
